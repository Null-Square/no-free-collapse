# Proof map and figures

The current primary manuscript is a theorem-and-proof paper; it does not require generated cover art or numerical performance figures.

Its dependency order is:

`complementary-subset incidence identity -> two PSD slack decompositions -> sharp weighted-operator bound -> critical hafnian recursion -> interlacing and counting -> averaged hierarchy`.

Roos's parity-free subset-convolution corollary supplies a separate input to the hybrid product. The fixed-order density proposition determines the crossover region. The six-variable equality proof and real collision-free GBS corollary use the main theorem with their own explicit hypotheses.

Older projection-rank diagrams describe a valid historical route, not an unresolved prerequisite for the global PSD theorem. The original quantum-inspired repository cover is not scientific evidence and is not included in the manuscript submission materials.

Any future numerical figure must be generated from the archived code and data, retain its seed and normalization, and label diagnostics as diagnostics. No simulated plot should be presented as a physical GBS experiment.
