# AI assistance: factual scope and approval-dependent wording

OpenAI ChatGPT was used for theorem exploration, proposed proofs and extensions, code and test generation, literature triage, manuscript organization and substantial drafting. This was not limited to spelling or grammar assistance. Connected GitHub tools were used to inspect and update the repository; web tools supported source checks. The archived code, formulas, manuscript revisions and test evidence should be retained with the approved research record.

A final declaration should name the actual tools and model versions recorded by the human authors and accurately describe these roles. Do not invent a historical model version. The present assistant identifies as GPT-6 Astra Pro; that does not establish the model version of every earlier project session. Verify the session records before finalizing that field.

The manuscript methods/reproducibility section should explain the research use, and a separate end-of-paper declaration should explain drafting use. Elsevier's current policy distinguishes these two. AI must not be listed as an author.

Approval-dependent final sentence, to be used only after true: “The authors verified the mathematical arguments, computational checks and cited sources, revised the generated material as needed, approved the final manuscript, and take responsibility for its content.” It must not be represented as completed in the current author-review candidate.
